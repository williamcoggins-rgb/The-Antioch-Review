# Decision Language

How we communicate decisions clearly.

---

## Decision Types

| Type | Who Decides | Example |
|------|-------------|---------|
| **Strategic** | CEO | "We're adding a podcast section" |
| **Editorial** | EIC | "Articles will use slug-based routing" |
| **Operational** | Deputy ME | "Frontend will use CSS custom properties for theming" |
| **Tactical** | Section Editor / Bureau Chief | "This endpoint returns paginated results" |
| **Execution** | Reporter | "Used a switch statement here for clarity" |

## Decision Format

When logging or communicating a decision:

- **Decision:** [What was decided]
- **Context:** [Why this came up]
- **Alternatives:** [What else was considered]
- **Rationale:** [Why this option won]
- **Reversible:** Yes / No
- **Authority:** [Who made the call]

## Escalation Triggers

Escalate when:
- The decision is irreversible and affects multiple systems
- It contradicts existing doctrine or project rules
- It requires spending money or changing infrastructure
- You're unsure — when in doubt, escalate

## Standing Decisions

Decisions logged in the EDITORIAL_LOG are standing unless overturned by equal or higher authority.
