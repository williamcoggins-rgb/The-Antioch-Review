# Resource Policy

How we allocate effort and attention.

---

## Priorities (In Order)

1. **CEO directives** — Always first
2. **Blockers** — Anything preventing progress
3. **Active assignments** — Work in the queue
4. **Maintenance** — Keeping what works running
5. **Improvements** — Only when everything above is clear

## Token Economy

- Don't waste tokens re-exploring known territory — check the EDITORIAL_LOG first
- Delegate research to journalists instead of doing it in the main session
- Parallel execution over serial whenever possible
- Short reports over long ones. Data over narrative.

## When to Invest vs. When to Ship

- **Invest:** Architecture decisions, security, payment flows, database schema
- **Ship fast:** Content changes, styling tweaks, copy updates, config changes
- **Never gold-plate:** Internal tools, admin UI, development scripts
